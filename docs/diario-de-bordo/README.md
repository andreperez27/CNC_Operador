# Diário de bordo — CNC Operador

Um arquivo por dia de trabalho, nomeado `AAAA-MM-DD.md`.

Cada entrada tem um cabeçalho curto do que foi feito, seguido de bullets
objetivos: o que foi implementado, o que foi corrigido, decisões tomadas e
pendências em aberto pra próxima sessão. Sem duplicar o que já está em commit
message — o diário registra raciocínio e decisão.

DIRETRIZ PERMANENTE: antes de fazer commit e antes de publicar/build de
produção, atualizar (ou criar) o arquivo do dia corrente.
